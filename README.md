# desafio.adm

Desafio ADM: jogo de missões do ADM Experience, do Técnico em Administração da EEB Eurico Pinz. O aluno do 9º ano enfrenta situações do dia a dia, decide como quem administra e vê a consequência. No fim, recebe um crachá com o cargo conquistado.

Cada missão tem quatro etapas: a missão (10 s), as opções (40 s), a consequência (20 s) e o resultado, com a área da Administração usada (20 s). A ordem das missões e das cartas é sorteada a cada partida.

- Jogar: abra o `index.html` ou a página do GitHub Pages. Funciona sem internet.
- Editar as missões, os tempos e os textos: `dados.js`.
- Conferir o conteúdo depois de editar: `node teste.js`.
- Atalhos: A, B, C (ou 1, 2, 3) escolhem a carta; P pausa o tempo; Enter avança.
